Task: R12-T043
Section: "Recover a deleted tag" in README.md
Target Commands: git fsck --unreachable | grep tag | git update-ref refs/tags/<tag_name> <hash>

1. Environment & Setup:
- Initial branch: main
- Author Name: Course Student
- Author Email: student@example.invalid
- Clean Git Config: GIT_CONFIG_NOSYSTEM=1, GIT_CONFIG_GLOBAL=/dev/null

2. Repository Construction Steps:
- Initialize:
    git init -b main
    git config user.name "Course Student"
    git config user.email "student@example.invalid"

- Commit A:
    printf "alpha\n" > notes.txt
    git add notes.txt
    git commit -m "Commit A: create notes.txt"

- Commit B:
    printf "beta\n" >> notes.txt
    git add notes.txt
    git commit -m "Commit B: append beta to notes.txt"
    git branch topic

- Commit C:
    printf "one\n" > todo.txt
    git add todo.txt
    git commit -m "Commit C: create todo.txt"

3. Tag Creation & Mistake:
- Create annotated tag v1.0 at topic (Commit B):
    git tag -a v1.0 -m "Release v1.0" topic
- Accidental tag deletion:
    git tag -d v1.0

4. Recovery Sequence:
- Find unreachable tag object:
    git fsck --unreachable | grep tag
- Restore ref using git update-ref:
    git update-ref refs/tags/v1.0 <tag_hash>
- Verification:
    git rev-parse v1.0^{tree}
    git show v1.0:notes.txt
