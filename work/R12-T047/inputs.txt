Task: R12-T047
Section: "I accidentally did a hard reset, and I want my changes back" in README.md
Target Commands:
    (main)$ git reflog
    (main)$ git reset --hard SHA1234

1. Environment & Setup:
- Initial branch: main
- Author Name: Course Student
- Author Email: student@example.invalid
- Clean Git Config: GIT_CONFIG_NOSYSTEM=1, GIT_CONFIG_GLOBAL=/dev/null

2. Repository Construction Steps:
- Initialize:
    git init -b main
    git config user.name "Course Student"
    git config user.email "student@example.invalid"

- Commit A:
    printf "alpha\n" > notes.txt
    git add notes.txt
    git commit -m "Commit A: create notes.txt"

- Commit B:
    printf "beta\n" >> notes.txt
    git add notes.txt
    git commit -m "Commit B: append beta to notes.txt"
    git branch topic

- Commit C:
    printf "one\n" > todo.txt
    git add todo.txt
    git commit -m "Commit C: create todo.txt"

3. Accidental Hard Reset:
    git reset --hard HEAD~1
(moves HEAD from Commit C to Commit B)

4. Failure Diagnosis & Correction:
- Violated Precondition:
    git reset --hard SHA1234
    (fails with non-zero exit code 128: unknown/invalid revision)
- Repaired Command:
    git reset --hard HEAD@{1}
    (successfully restores HEAD and working tree to Commit C)
