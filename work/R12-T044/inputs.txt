Task: R12-T044
Section: "Restore a deleted file" in README.md
Target Commands: git rev-list -n 1 HEAD -- filename | git checkout deletingcommitid^ -- filename

1. Environment & Setup:
- Initial branch: main
- Author Name: Course Student
- Author Email: student@example.invalid
- Clean Git Config: GIT_CONFIG_NOSYSTEM=1, GIT_CONFIG_GLOBAL=/dev/null

2. Repository Construction Steps:
- Initialize:
    git init -b main
    git config user.name "Course Student"
    git config user.email "student@example.invalid"

- Commit A:
    printf "alpha\n" > notes.txt
    git add notes.txt
    git commit -m "Commit A: create notes.txt"

- Commit B:
    printf "beta\n" >> notes.txt
    git add notes.txt
    git commit -m "Commit B: append beta to notes.txt"
    git branch topic

- Commit C:
    printf "one\n" > todo.txt
    git add todo.txt
    git commit -m "Commit C: create todo.txt"

3. Branch Switching & Deletion:
- Switch to topic:
    git checkout topic
- Delete notes.txt on topic:
    git rm notes.txt
    git commit -m "Commit D: delete notes.txt on topic"

4. Restoration on topic:
- Locate deleting commit using HEAD:
    git rev-list -n 1 HEAD -- notes.txt
- Checkout parent of deleting commit:
    git checkout <deleting_commit>^ -- notes.txt
- Commit restoration on topic:
    git commit -m "Commit E: restore notes.txt on topic"
